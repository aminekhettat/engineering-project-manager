architecture, requirements, planning, quality, configuration, cost,
schedule, interfaces, implementation or release.

## Rules

- Significant technical and project decisions must be recorded.
- Accepted decisions must be traceable to affected work products.
- Superseded decisions must not be deleted.
- A superseding decision must reference the previous Decision ID.
- Decision IDs are stable and must never be reused.
