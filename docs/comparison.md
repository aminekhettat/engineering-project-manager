# Positioning and related projects

Project Manager focuses on engineering project state and the evidence behind a
release decision. Choose tools by workflow fit, not repository size or star count.

| Project | Published focus | Relationship to this skill |
| --- | --- | --- |
| [Superpowers](https://github.com/obra/superpowers) | Coding workflows with composable skills and agent integrations. | Useful reference for guided execution and contributor structure; this skill adds explicit project registries and release audits. |
| [Anthropic skills](https://github.com/anthropics/skills) | A catalog of self-contained skill examples. | Reference for packaging and progressive disclosure, not a project-control product comparison. |
| [Planning with Files](https://github.com/OthmanAdi/planning-with-files) | Persistent planning and progress in files. | A lighter planning approach; this skill introduces stricter revision, lifecycle and evidence semantics. |
| [PM Skills](https://github.com/phuryn/pm-skills) | Product management discovery, strategy and related workflows. | Complementary product work; this skill emphasizes engineering execution, traceability and delivery control. |
| [Last 30 Days](https://github.com/mvanhorn/last30days-skill) | Research skill with documented installation and examples. | A packaging reference for a substantial single skill with tests outside its runtime. |
| [Vercel agent skills](https://github.com/vercel-labs/agent-skills) | A skill collection with install and distribution conventions. | Reference for discovery and a short installation path. |

This comparison describes the repositories' published positioning, observed on
2026-09-17. It is not a feature-completeness benchmark or an endorsement by their
maintainers. Capabilities and structures can change. Popularity is influenced by
age, distribution and existing audiences; no structure guarantees adoption.

The adopted conventions are deliberately concrete: a nested self-contained
runtime, a short README, separate contributor tests, an executed demonstration,
clear compatibility boundaries, contribution paths and reproducible archives.
One coherent skill is retained instead of splitting it into an artificial catalog.
